Film production chat app

A custom Electron app commissioned for a feature film shoot, designed to display real-time chat conversations on an actor’s laptop as an on-screen prop. I’m now independently rebuilding it with React and Vite.

Project
On-screen film prop
Role
Design and development
Stack
React, Vite, Electron, JavaScript, CSS
Status
Refactor in progress

The app had to work as a convincing interface for the actor while giving the crew precise control over conversations, user states, and repeatable takes during production.

Production constraint

The on-camera view lets the actor type and send messages, and the logged-in user can be swapped to show the conversation from different characters’ perspectives.

A separate crew interface handles everything else: adding and editing users, changing online status, sending messages as other users, saving templated messages for reshoots, and switching the screen between direct messages and video chats.

Iterating on set

After the first shoot day, the crew needed a way to reshoot without manually retyping the script. They also needed the ability to reorder and edit messages sent in the chat.

I added a template system that posts pre-written messages with a configurable typing-indicator delay and implemented a custom right-click menu for editing messages in the chat.

Rebuilding the app

The original codebase grew organically under production pressure. The ongoing refactor introduces component-based architecture, a slide-out settings panel, and cleaner separation between the two interfaces.
