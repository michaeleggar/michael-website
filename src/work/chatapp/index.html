Two interfaces

The on-camera view lets the actor type and send messages, and the logged-in user can be swapped to show the conversation from different characters’ perspectives. A separate crew interface handles everything else: adding and editing users, changing online status, sending messages as other users, saving templated messages for reshoots, and switching between direct messages and video chats.

Iterating on set

After the first shoot day, the crew needed a way to reshoot without manually retyping the script. They also needed the ability to reorder and edit messages already sent in the chat. I added a template system with a configurable typing-indicator delay and a custom right-click menu for editing messages.

Try the original

This is the version that ran on set, changed only to run in a browser instead of Electron. Send a message or request a video call from the control panel, and it appears on the chat screen.

Rebuilding it in React

The original codebase grew organically under production pressure. After the shoot I rebuilt it with React and Vite. One reducer now drives both windows and keeps them in sync over BroadcastChannel. The rebuild adds chat rooms, a slide-out settings panel that can pop out into its own window, and a layout that works down to phone size.

Saved messages send with a typing delay, so the chat screen shows someone typing before their message lands. You can also run the whole thing from the cog next to Sadie’s name.
