Retirement Investment Advisors website

Retirement Investment Advisors is a fiduciary firm based in Oklahoma City. It needed a redesign that could organize a growing library of resources, financial tools, and market commentary, all managed by staff with no technical background.

About the project

Role

  • Design
  • Development

Stack

  • WordPress
  • Elementor
  • ACF
  • JavaScript
  • CSS

Link

  • theretirementpath.com

Taxonomy system

I built a resource library using custom post types and taxonomy-driven fields through ACF. New content gets tagged and featured across the site automatically. Financial briefs and market commentary work the same way, so staff can add content and the rest is handled for them.

Reusable content

I applied the same approach at the page level, creating reusable sections so the team can build and update pages independently without needing a developer.

Visual refresh

The firm’s branding elements have held steady for nearly a decade. I kept the classic navy and gold while opening the site up with warm photography, more white space, and a refreshed type system.
