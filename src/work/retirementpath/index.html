Retirement Investment Advisors website

A redesign that organizes a growing library of resources, financial tools, and market commentary for an Oklahoma City fiduciary firm.

Client
Retirement Investment Advisors
Role
Design and development
Platform
WordPress, Elementor, ACF
Live site
theretirementpath.com ↗

The firm needed a clearer site that staff with no technical background could manage. I designed the visual refresh and built a reusable system that keeps resources and commentary organized as the library grows.

Content system

I built a resource library using custom post types and taxonomy-driven fields through ACF. New content gets tagged and featured across the site automatically. Financial briefs and market commentary work the same way.

I applied that approach at the page level, creating reusable sections so the team can build and update pages independently without needing a developer.

Visual refresh

The firm’s branding elements have held steady for nearly a decade. I kept the classic navy and gold while opening the site up with warm photography, more white space, and a refreshed type system.
