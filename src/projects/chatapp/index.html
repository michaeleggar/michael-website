In the scene, a teenager with cancer is up late in a group chat with friends who understand. The camera needed a real conversation on her laptop, one the actor could read and answer in the moment. So I built the app in Electron as two windows sharing one conversation. Hers is the chat the camera sees. The crew’s holds everyone else. From there they added characters, set who was online, sent lines as anyone on cue, and switched her screen to a video call.

Both builds run below, the original from the shoot and the React rebuild. Cue a line from the crew’s side and the character types for a moment before it lands. Or type back as Sadie.

{% include "chat-demo.njk" %}

The first shoot day showed what was missing. Every reshoot meant retyping the script by hand, and a message, once sent, couldn’t be fixed or moved. So I added saved lines that post after an adjustable typing delay, a right-click menu for editing and reordering messages in place, and a reset between takes.

{{ clip(recordings.crew) }} {{ clip(recordings.edit) }}

The original grew fast under production pressure, so after the shoot I rebuilt it with React and Vite. A single reducer drives both windows, and each one replays the other’s changes, so the actor’s screen and the crew’s side always agree. The crew’s tools now live in a settings panel that slides out beside the chat, or pops out into a window of its own. The rebuild also adds chat rooms and a layout that works on a phone.

On the monitor it reads as an ordinary group chat late at night. That was the job.
