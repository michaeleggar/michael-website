The crew interface initially controlled adding and editing users, changing online statuses, toggling typing indicators, sending messages as any user, and switching the on-film screen between direct messages and video chats.

{% include "chat-demo.njk" %}

After the first day on set, the crew needed a way to reshoot scenes without retyping the script by hand each time. I added a template system that lets the crew save messages alongside typing indicator delays. I also added a way to edit and reorder messages after they’d been sent.
